# deep_learning_hc_final
UIUC Deep Learning for Healthcare Final Project
by Toby Maggert and Stephen Imhoff

This project is an attempt to replicate and update the paper Multi-Label Generalized Zero Shot Learning for the Classification of Disease in Chest Radiographs
Please view this [repo](https://github.com/nyuad-cai/CXR-ML-GZSL/tree/master?tab=readme-ov-file) for the original code. 

You'll notice two separe folders, one for a local implementation run on a 3060 TI and one for an implementation on Google Colab. To train and evaluate the network, download the [NIH chest x-ray dataset](https://nihcc.app.box.com/v/ChestXray-NIHCC).
